# 钢琴调律助手 · Inharmonic Tuning Suite

面向平板的专业钢琴拉伸调律应用。普通调音器只认基频,而真实钢琴弦有抗弯刚度,
泛音频率按 **Young 非谐模型** 偏离整数倍:

```
f_n = n · f₁ · √(1 + B·n²)
```

本应用对每根弦录一声,从频谱中定位前十几个泛音峰并拟合出非谐系数 **B**,
攒够若干弦后推算整台琴 B 随音高的分布,再按**八度(2:1)、十二度(3:1)、
双八度(4:1)分音拍频最小**原则,求解这台琴专属的拉伸调律曲线。

## 四个页面

| 页面 | 功能 |
|------|------|
| 🎚 **测弦** | 选键录音 → 频谱分音匹配 → 加权最小二乘拟合 B,实时对照理论值偏差 |
| 📈 **调律曲线** | 整琴 B 分布、本琴拉伸曲线 vs Railsback 公开统计曲线、实测键标注 |
| 🎯 **逐键调律** | 针盘式音分表、多泛音融合测频、同音弦拍频、八度/十二度参考拍频 |
| 🗂 **琴档案** | 5 台不同尺寸钢琴弦列、88 键物理参数、JSON 导入导出、localStorage 持久化 |

顶部「模拟弦演示」开关:无麦克风时,内置刚性弦合成器(同样遵循 Young 模型,
含三弦微失调与击弦瞬态)驱动完整分析链路,可离线演示与测试。

## 技术架构

```
src/
├── audio/
│   ├── tuning-worklet.js  AudioWorklet:采集 + Hann 窗 + radix-2 FFT + 峰提取
│   ├── engine.ts          AudioContext 生命周期、麦克风/合成双输入、延迟测量
│   ├── session.ts         页面共享的音频会话
│   └── synth.ts           刚性弦声音合成器(演示与真值来源)
├── math/
│   ├── fft.ts             迭代 FFT、抛物线亚 bin 插值、自适应峰检测
│   ├── inharmonic.ts      Young 模型、理论 B、线性化加权最小二乘拟合
│   ├── tuning.ts          整琴 B 表(log 二次拟合)+ 最小拍频曲线求解
│   ├── beats.ts           同音弦裂峰聚类 + 时域包络自相关拍频
│   ├── analyzer.ts        实时多泛音融合测频、测弦流程
│   └── acoustics.ts       频率/音分/音名换算
├── data/pianos.ts         5 台虚构钢琴的物理自洽弦列 + Railsback 锚点
├── state/store.ts         状态管理与持久化
└── ui/                    四个平板页面 + Canvas 频谱/曲线绘制
```

### 关键工程决策

- **音频分析全在 AudioWorklet**:渲染线程做 FFT 与峰提取,主线程只做模型拟合和 UI,
  UI 卡顿不影响采集;帧通过 Transferable 零拷贝回传。
- **B 拟合用线性化加权回归**:`(fₙ/n)² = f₁²(1+Bn²)` 把非线性模型化为直线,
  权重取峰能量,两轮迭代(粗匹配 → 精匹配)。
- **曲线求解为带权最小二乘**:无拍条件是关于音分偏离量的线性约束,
  叠加相邻平滑正则、平均律弱先验与 A4 强锚点,Jacobi 迭代求解。
- **实时测频按分音序号加权**:高分音每窗周期更多、亚 bin 测频更准,
  显著压低低频键读数误差;再做离群剔除与时间 EMA 平滑。

## 物理参数说明

5 台钢琴(118/131 立式、168/186/274 三角)的弦列由物理关系自洽生成:
裸弦先按真实线规表选径、设定目标张力,再由 `T = μ(2Lf)²` 反推弦长;
缠弦按张力反推铜绕组。所有弦的张力落在 580–980 N 真实区间,
裸弦线径 0.72–1.32 mm,理论 B 由 `B = π³Ed⁴/(64TL²)` 计算。
